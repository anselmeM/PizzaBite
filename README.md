# PizzaBite 🍕

A modern, responsive, and high-performance front-end clone of the traditional Italian pizzeria website "Marcello" (rebranded here as **PizzaBite**).

## Overview

PizzaBite is a beautifully crafted static website designed with a mobile-first approach. It showcases an authentic wood-fired pizzeria brand, featuring elegant typography, engaging micro-animations, and a responsive layout that scales perfectly from mobile devices to large desktop monitors.

## Features

*   **Responsive Mobile-First Design:** Fluidly adapts to mobile, tablet, and desktop viewports using CSS Grid, Flexbox, and fluid typography (`clamp()`).
*   **Interactive Split-Screen Menu:** A premium fullscreen overlay menu that stacks on mobile and expands into an elegant 70/30 split-screen (navigation and lifestyle imagery) on desktop viewports.
*   **Custom Micro-Animations:** Hand-crafted CSS transitions including:
    *   Organic wave effects on the hamburger menu icon.
    *   Hover scale and rotate interactions on the circular pizza images.
    *   Dynamic, scroll-linked typing reveal on cursive watermarks.
    *   Expand-from-center focus underlines on form inputs.
*   **Performance Optimized:** Pure Vanilla HTML, CSS, and JavaScript with no heavy frameworks or dependencies.
*   **Transparent Image Assets:** Pizza assets have been processed to be perfectly transparent, feathered circles, allowing them to float naturally on alternating background colors.

## Technologies Used

*   **HTML5:** Semantic and accessible structure.
*   **CSS3:** Custom properties (variables), Grid, Flexbox, keyframe animations, and advanced pseudo-element styling.
*   **Vanilla JavaScript:** Lightweight DOM manipulation for the shopping cart drawer, mobile menu toggling, interactive testimonial tabs, and scroll-linked animations.

## Getting Started

Because PizzaBite is a static front-end project with no build tools or dependencies required, you can run it instantly.

1.  Clone the repository:
    ```bash
    git clone https://github.com/anselmeM/PizzaBite.git
    ```
2.  Navigate into the project directory:
    ```bash
    cd PizzaBite
    ```
3.  Open the `index.html` file in your preferred web browser.
